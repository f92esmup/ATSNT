# Task history

The files in this folder are the working logs of earlier tasks: the decisions taken, the
verification evidence and the state of each batch when it was written. They are kept as history.

They name components that the swarm-only refactor removed: BigQuery, GCS and Cloud Batch, the
portfolio and universe stack, the CUSUM and order-flow strategies, and the Binance live gateway.
Do not read them as a description of the current code. The current plan is in `docs/plan/`, its
status is in `docs/ROADMAP.md`, and the removed documents are in `docs/archive/`.
